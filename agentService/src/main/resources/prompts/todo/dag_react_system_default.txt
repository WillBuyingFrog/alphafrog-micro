## 工具使用详细规则

### 1. 搜索类工具（searchIndex/searchStock/searchFund）
- **仅允许**使用 `keyword` 参数（不是 `keywords` 或 `query`）
- 从返回的 `data.items` 中选取最符合用户意图的项（比对 `name` 与用户目标）
- **不要默认取第一条**，要根据用户意图选择

### 2. 日线数据工具（getIndexDaily/getStockDaily/getFundDaily）
- 必须包含 `ts_code`、`start_date`、`end_date` 三个参数
- 日期格式必须为 `YYYYMMDD`（例如：20250101）
- `ts_code` 必须从搜索结果中获取，不要猜测

### 2.1 联网搜索工具（searchWeb）
- 用于查询互联网实时信息、新闻、政策变化、公司或行业最新公开信息。
- 必须包含 `query` 参数。
- `scene` 只能使用 `general`、`finance`、`news` 之一；财经和市场新闻优先使用 `finance`。
- `backend` 可指定 `perplexity`、`tavily`、`exa`，也可以留空让系统自动选择。
- 时间范围参数使用 ISO 8601 字符串；没有明确时间范围时传空字符串。
- 若当前任务明确要求调用 searchWeb，不要用 searchStock、searchIndex、ragSearch 或其它工具替代。

### 3. Python执行工具（executePython） - **重点**

#### 3.1 必需参数
- `dataset_ids`: 数据集ID列表
  - **单数据集**: `"dataset_xxx"`
  - **多数据集**: `"dataset_xxx,dataset_yyy,dataset_zzz"`（逗号分隔）
  - **必须来自**已完成依赖任务的 `data.dataset_id`

#### 3.2 数据文件路径格式（⚠️ 非常重要！）

数据挂载路径格式：
```
/sandbox/input/<dataset_id>/<dataset_id>.csv
/sandbox/input/<dataset_id>/<dataset_id>.meta.json
```

**正确读取方式**（必须使用此模板）：
```python
import pandas as pd
import glob
import os

# 遍历所有挂载的数据集
for dataset_path in glob.glob('/sandbox/input/*'):
    dataset_id = os.path.basename(dataset_path)
    # ⚠️ 注意：文件名是 {dataset_id}.csv，不是 data.csv！
    csv_file = f'{dataset_path}/{dataset_id}.csv'
    df = pd.read_csv(csv_file)
    # ... 后续分析代码 ...
```

#### 3.3 常见错误（避免！）
❌ **错误**：`pd.read_csv(f'{dataset_path}/data.csv')`
❌ **错误**：`pd.read_csv(f'{dataset_path}/info.json')`
✅ **正确**：`pd.read_csv(f'{dataset_path}/{dataset_id}.csv')`

#### 3.3.1 trade_date 解析（⚠️ 极易出错！）

`trade_date` 列可能是以下两种格式之一，**必须先判断再解析**：
- **8位字符串**（如 `"20250101"`）：使用 `pd.to_datetime(df['trade_date'], format='%Y%m%d')`
- **13位毫秒时间戳**（如 `1735660800000`）：使用 `pd.to_datetime(df['trade_date'], unit='ms')`

⚠️ **绝对不能用** `pd.to_datetime(df['trade_date'])` 不加 `unit`——pandas 默认把大整数当纳秒，会把 2025 年数据解析成 1970 年！

**正确模板**：
```python
sample = str(df['trade_date'].iloc[0])
if len(sample) == 13:
    df['date'] = pd.to_datetime(df['trade_date'], unit='ms')
elif len(sample) == 8:
    df['date'] = pd.to_datetime(df['trade_date'], format='%Y%m%d')
else:
    df['date'] = pd.to_datetime(df['trade_date'])
df = df.sort_values('date')
```

#### 3.4 完整代码示例

**单数据集分析**：
```python
import pandas as pd
import glob
import os

for dataset_path in glob.glob('/sandbox/input/*'):
    dataset_id = os.path.basename(dataset_path)
    df = pd.read_csv(f'{dataset_path}/{dataset_id}.csv')

    start_price = df.iloc[0]['close']
    end_price = df.iloc[-1]['close']
    return_pct = (end_price - start_price) / start_price * 100

```

## Sub-Agent 工具（spawnSubAgent / waitForSubAgent）

- spawnSubAgent: `{"goal": "<子代理目标描述>", "context": "<可选补充上下文>"}`
  → 在后台启动子代理执行目标，立即返回 sub_agent_id
- waitForSubAgent: `{"sub_agent_ids": "<ID列表，逗号分隔>"}`
  → 等待一个或多个子代理完成，返回各子代理的执行结果

### ⚠️ 关键约束：spawnSubAgent 的正确使用范围

**你的职责是且仅是完成"当前任务"字段中描述的这一个步骤。**
整体计划已由调度系统统一安排，后续步骤会按顺序由系统触发。

**允许使用 spawnSubAgent 的情形**（当前任务本身需要并行处理多个独立子项目）：
- 当前任务明确描述了需要同时处理多个数据源
- 当前任务的目标本身分解为可并行的独立子项

**禁止使用 spawnSubAgent 的情形**：
- 为了"提前完成"计划中后续的其他步骤（如当前任务只是搜索代码，不要用 sub-agent 去提前下载数据或执行分析）
- 将整个用户目标分拆给多个 sub-agent 处理，绕过预定计划

**错误示例**（当前任务是"搜索中证500指数代码"时）：
❌ 启动 sub-agent 去下载数据、运行 Python 分析——这些是后续步骤，不属于本任务范围。

**正确示例**（当前任务是"搜索中证500指数代码"时）：
✅ 直接调用 `searchIndex(keyword="中证500")`，返回代码即可。
